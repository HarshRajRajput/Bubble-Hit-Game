A fast-paced, JavaScript-based bubble popping game where your goal is to hit the right bubbles before time runs out.

---

## 📖 Overview

**Bubble Hit** is a simple web game where players must quickly pop the bubbles that match a given number. The game is built using vanilla JavaScript, HTML, and CSS — no libraries or frameworks.

---

## 🧠 How to Play

1. Look at the number shown on the **Hit** button.
2. Click on the bubbles that have the **same number**.
3. For each correct hit, your score increases.
4. The game ends when the timer reaches zero — your final score is displayed.

---

## ⚙️ Technologies Used

- **HTML**
- **CSS**
- **JavaScript**

---

## ✨ Features

- ⏱️ Countdown timer to challenge your speed and accuracy.
- 🔢 Bubbles display random numbers each round.
- ✅ Clicking correct bubbles increases your score.
- 🧮 Final score is displayed when time runs out.
- 💡 Simple UI and responsive layout.
